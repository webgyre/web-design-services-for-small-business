# Website Launch Checklist

Use this checklist before publishing a small business website.

## Content

- [ ] All pages have been proofread
- [ ] Contact information is correct
- [ ] Business hours are correct
- [ ] Calls to action work
- [ ] Testimonials are genuine
- [ ] Images have appropriate alt text

## Technical

- [ ] HTTPS works
- [ ] Domain resolves correctly
- [ ] Redirects are configured
- [ ] Forms deliver successfully
- [ ] Error pages work
- [ ] No unnecessary development files are public

## SEO

- [ ] Page titles are unique
- [ ] Meta descriptions are useful
- [ ] One clear H1 is used where appropriate
- [ ] Canonical URLs are configured where needed
- [ ] XML sitemap is available
- [ ] robots.txt is correct
- [ ] Search analytics tools are connected

## Performance

- [ ] Images are optimized
- [ ] Fonts are optimized
- [ ] Unused scripts are removed
- [ ] Mobile performance is checked
- [ ] Core Web Vitals are reviewed

## Accessibility

- [ ] Keyboard navigation works
- [ ] Focus states are visible
- [ ] Color contrast is sufficient
- [ ] Form labels are clear
- [ ] Images have meaningful alt text
- [ ] Reduced-motion behavior is considered

## Final test

- [ ] Test on mobile
- [ ] Test on tablet
- [ ] Test on desktop
- [ ] Test major browsers
- [ ] Test every important link
- [ ] Test every form
- [ ] Take a final backup
