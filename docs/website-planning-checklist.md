# Small Business Website Planning Checklist

Use this checklist before starting a website project.

## Strategy

- [ ] Define the primary business goal
- [ ] Identify the target audience
- [ ] Define the main conversion action
- [ ] Review competitors
- [ ] Identify the business differentiators
- [ ] Define the services or products to feature

## Structure

- [ ] Create the sitemap
- [ ] Define navigation
- [ ] List required pages
- [ ] Identify pages that need unique SEO targeting
- [ ] Plan internal links

## Content

- [ ] Write the homepage message
- [ ] Prepare service descriptions
- [ ] Prepare About content
- [ ] Collect testimonials
- [ ] Prepare FAQs
- [ ] Collect images and brand assets
- [ ] Prepare contact information

## Design

- [ ] Confirm logo
- [ ] Confirm brand colors
- [ ] Confirm typography
- [ ] Define visual style
- [ ] Design mobile layouts
- [ ] Review accessibility and contrast

## Development

- [ ] Choose technology/CMS
- [ ] Configure domain
- [ ] Configure hosting
- [ ] Set up HTTPS
- [ ] Implement analytics
- [ ] Configure forms
- [ ] Test integrations

## SEO

- [ ] Write unique page titles
- [ ] Write useful meta descriptions
- [ ] Use logical heading structure
- [ ] Optimize images
- [ ] Create clean URLs
- [ ] Add internal links
- [ ] Create XML sitemap
- [ ] Check robots.txt
- [ ] Connect relevant search tools

## Launch

- [ ] Test mobile
- [ ] Test desktop
- [ ] Test forms
- [ ] Test navigation
- [ ] Check broken links
- [ ] Check page speed
- [ ] Check metadata
- [ ] Check analytics
- [ ] Backup the site
- [ ] Confirm domain and redirects
